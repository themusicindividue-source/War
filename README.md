# WAR

Juego 2D hecho en Godot en el que hay que disparar a los objetivos que salen de detrás de un escudo antes de que escapen.

## Cómo se juega

- Haz clic en los objetivos para destruirlos.
- El escudo bloquea los clics: los objetivos solo se pueden destruir cuando salen de su zona.
- Si dejas escapar 5 objetivos, pierdes.
- Si aguantas hasta que el tiempo llegue a 0, ganas y pasas al siguiente nivel.

## Cómo abrir el proyecto

1. Instala Godot 4.
2. Descarga o clona este repositorio.
3. Abre Godot, pulsa Importar y elige el archivo `project.godot`.
4. Ejecuta con F5.
